**Goal:** Build `bin/peon` — a harness-agnostic shell script that dispatches implementation tasks to external CLI agents (Codex, Grok) in isolated git worktrees — plus a `peon-poke` Claude skill teaching the foreman workflow, restructuring the repo to `skills/plan-check/` + `skills/peon-poke/`.

**Architecture:** Two layers per the approved spec (`docs/superpowers/specs/2026-07-29-peon-poke-design.md`): (1) `bin/peon` encapsulates all provider incantations behind deterministic commands (`dispatch`, `list`, `report`, `diff`, `poke`, `merge`, `scrap`); (2) a prose skill teaches Claude the workflow. Peon output lands on namespaced `peon/<slug>` branches in worktrees under `$PEON_HOME/worktrees/`, never reaching the real tree without orchestrator review and explicit `merge`. Peon metadata lives OUT of the worktree at `$PEON_HOME/meta/<slug>.json` (slug = global identity, atomically reserved). A test-only `fake` provider plus a `PEON_DRY_RUN` seam let the entire lifecycle be tested deterministically without provider calls; live provider tests are the final gate.

**Tech Stack:** bash (macOS 3.2-compatible), git worktrees, python3 (JSON read/write + JSONL parse only), codex-cli 0.145.0, grok 0.2.112.

- **Join:** Task 8 (install/sync) then Task 9 (live verification) — sequential, after A and B are merged.

## Global Constraints

- **bash 3.2 compatible** (macOS `/bin/bash`): no associative arrays, no `${var,,}`, no `mapfile`. Shebang `#!/usr/bin/env bash`.
- **Runtime deps: git, python3 (+ uuidgen for grok dispatch only). Never jq** (missing on some of the user's machines).
- **No hardcoded absolute user paths** — use `$HOME`; all state under `PEON_HOME` (default `$HOME/.peon`), overridable via env for test isolation. Layout: `$PEON_HOME/{worktrees,logs,meta}`.
- Worktrees: `$PEON_HOME/worktrees/<repoBasename>-<slug>`; branches: `peon/<slug>`; metadata: `$PEON_HOME/meta/<slug>.json` (single source of truth for discovery; stores the worktree path explicitly). **Nothing is written inside the worktree except by the peon itself.**
- **Slugs are global identities:** validated (`^[a-z0-9][a-z0-9-]{0,39}$` + `git check-ref-format --branch`), reserved atomically (noclobber create of the meta file) before any git mutation. Active peon = meta file exists.
- **Contract gates:** after every provider run the harness verifies (a) ≥1 commit since the gate ref — `base_sha` for dispatch, pre-poke `HEAD` for poke; (b) `PEON_REPORT.md` committed in `HEAD`; (c) worktree clean. Violation = loud failure, worktree preserved for inspection.
- **Never `codex exec resume --last`** — always resume by explicit session id (parallel-safety).
- Codex dispatch: `codex exec --json -s workspace-write -c approval_policy=never`. Codex resume: `codex exec resume <id> -c sandbox_mode="workspace-write" -c approval_policy=never` — **resume has no `-s` flag** (verified 0.145.0).
- Grok: `--sandbox workspace` + approve strategy from `GROK_APPROVE` (default `mode:auto` → `--permission-mode auto`; `always` → `--always-approve`); pinned new session `-s <uuid>`, resume `--resume <uuid>`. Task 9 live-locks the default.
- `PEON_DRY_RUN=1`: providers are not invoked and their CLIs need not be installed (preflight skipped); the exact command line is recorded to `$LOG_ROOT/<slug>.cmd`.
- Spec invariants: hub-and-spoke (no peon-to-peon state), draft-until-reviewed, no autonomous merge, one peon per task.
- After every commit in the project repo: `git push`. The `~/.claude` repo has no remote — commit only.
- Test file `tests/peon.test.sh` runs standalone (`bash tests/peon.test.sh`) on a machine with NO provider CLIs, exits non-zero on any failure.

```bash
slugify() {
  printf '%s' "$1" | tr '[:upper:]' '[:lower:]' \
    | sed -e 's/[^a-z0-9]\{1,\}/-/g' -e 's/^-//' -e 's/-$//' | cut -c1-30 \
    | sed -e 's/-$//'
}

validate_slug() {
  printf '%s' "$1" | grep -qE '^[a-z0-9][a-z0-9-]{0,39}$' \
    || die "invalid slug: '$1' (lowercase alphanumerics and hyphens, max 40 chars)"
  git check-ref-format --branch "peon/$1" >/dev/null 2>&1 \
    || die "slug is not a valid git branch component: $1"
}

json_str() { python3 -c 'import json,sys; print(json.dumps(sys.argv[1]))' "$1"; }

resolve_repo() {
  git -C "$1" rev-parse --show-toplevel 2>/dev/null || die "not a git repository: $1"
}

require_clean() {
  [ -z "$(git -C "$1" status --porcelain)" ] || die "$2 has uncommitted changes (commit/stash first, or --force to dispatch anyway)"
}

require_peon_contract() {
  local wt="$1" since="$2"
  [ "$(git -C "$wt" rev-list --count "$since..HEAD")" -ge 1 ] \
    || die "peon contract violation: no commits since $since — worktree preserved at $wt ('peon report'/'peon scrap')"
  git -C "$wt" cat-file -e "HEAD:PEON_REPORT.md" 2>/dev/null \
    || die "peon contract violation: PEON_REPORT.md not committed — worktree preserved at $wt"
  [ -z "$(git -C "$wt" status --porcelain)" ] \
    || die "peon contract violation: uncommitted changes left behind — worktree preserved at $wt"
}

reserve_slug() {
  mkdir -p "$META_ROOT"
  ( set -C; : > "$META_ROOT/$1.json" ) 2>/dev/null \
    || die "slug already in use: $1 (see 'peon list'; slugs are global)"
}

write_meta() {
  cat > "$META_ROOT/$slug.json" <<EOF
{
  "slug": "$slug",
  "provider": "$provider",
  "session": "$session",
  "repo": $(json_str "$repo"),
  "worktree": $(json_str "$wt"),
  "base_sha": "$base_sha",
  "branch": "peon/$slug",
  "task": $(json_str "$task"),
  "created": "$(date -u +%Y-%m-%dT%H:%M:%SZ)"
}
EOF
}

update_meta_session() {
  python3 - "$META_ROOT/$1.json" "$2" <<'PYEOF'
import json, sys
p, sess = sys.argv[1], sys.argv[2]
m = json.load(open(p))
m["session"] = sess
json.dump(m, open(p, "w"), indent=2)
PYEOF
}

dispatch_prompt() {
  cat <<EOF
You are a "peon": an autonomous implementation agent working in an isolated git worktree on branch peon/$slug. Complete the task below, nothing more.

Rules:
- Commit ALL your changes to the current branch with clear commit messages.
- When done, write PEON_REPORT.md at the repo root covering: what changed, why, how you verified it, open questions. Commit it too.
- Leave the worktree clean: no uncommitted or untracked files.
- Do not push. Do not switch branches. Do not touch files outside this worktree.

Task:
$task
EOF
}

run_fake() {
  local slug="$1" wt="$2" pf="$3"
  SESSION="fake-$slug"
  if [ "${PEON_FAKE_FAIL:-0}" = "1" ]; then
    ( cd "$wt" && echo "half-done" > HALF_DONE.txt )   # simulates a provider dying mid-task
    return 1
  fi
  ( cd "$wt" \
    && cat "$pf" >> "FAKE_WORK-$slug.txt" \
    && git add "FAKE_WORK-$slug.txt" && git commit -qm "fake: do task" \
    && printf '# Peon Report\n\nDid the fake task.\n' > PEON_REPORT.md \
    && git add PEON_REPORT.md && git commit -qm "fake: report" )
  if [ "${PEON_FAKE_DIRTY:-0}" = "1" ]; then
    ( cd "$wt" && echo "oops" > LEFTOVER.txt )         # trips the contract gate
  fi
}

cmd_dispatch() {
  local provider="" task="" repo="$PWD" base="HEAD" slug="" force=0
  provider="${1:-}"; shift || true
  task="${1:-}"; shift || true
  while [ $# -gt 0 ]; do
    case "$1" in
      --repo)  [ -n "${2:-}" ] || die "--repo needs a value"; repo="$2"; shift 2 ;;
      --base)  [ -n "${2:-}" ] || die "--base needs a value"; base="$2"; shift 2 ;;
      --slug)  [ -n "${2:-}" ] || die "--slug needs a value"; slug="$2"; shift 2 ;;
      --force) force=1; shift ;;
      *) die "unknown dispatch option: $1" ;;
    esac
  done
  [ -n "$provider" ] || die "usage: peon dispatch <codex|grok> \"<task>\" [--repo DIR] [--base REF] [--slug NAME] [--force]"
  [ -n "$task" ] || die "no task given"
  case "$provider" in
    codex|grok)
      [ "${PEON_DRY_RUN:-0}" = "1" ] || command -v "$provider" >/dev/null 2>&1 || die "$provider CLI not installed" ;;
    fake) : ;;  # test-only provider
    *) die "unknown provider: $provider (codex|grok)" ;;
  esac
  command -v python3 >/dev/null 2>&1 || die "python3 required"
  [ "$provider" = "grok" ] && { command -v uuidgen >/dev/null 2>&1 || die "uuidgen required for grok"; }
  repo="$(resolve_repo "$repo")"
  git -C "$repo" var GIT_AUTHOR_IDENT >/dev/null 2>&1 || die "git author identity not configured in $repo (set user.name and user.email)"
  [ "$force" -eq 1 ] || require_clean "$repo" "repo $repo"
  local base_sha
  base_sha="$(git -C "$repo" rev-parse --verify "$base^{commit}" 2>/dev/null)" || die "cannot resolve base ref: $base"
  git -C "$repo" cat-file -e "$base_sha:PEON_REPORT.md" 2>/dev/null \
    && die "repo tracks PEON_REPORT.md at base — it would collide with the peon report artifact; rename it first"
  [ -n "$slug" ] || slug="$(slugify "$task")"
  [ -n "$slug" ] || die "could not derive a slug; pass --slug"
  validate_slug "$slug"
  local branch="peon/$slug"
  local wt="$WT_ROOT/$(basename "$repo")-$slug"
  git -C "$repo" show-ref --verify --quiet "refs/heads/$branch" && die "branch $branch already exists in $repo ('peon scrap $slug' or pick another --slug)"
  [ -e "$wt" ] && die "worktree path already exists: $wt"
  mkdir -p "$WT_ROOT" "$LOG_ROOT"

  reserve_slug "$slug"                                   # atomic global reservation
  trap 'rm -f "$META_ROOT/$slug.json"' EXIT              # release on pre-provider failure
  git -C "$repo" worktree add -q -b "$branch" "$wt" "$base_sha" || die "git worktree add failed"

  local session=""
  write_meta                                             # full metadata before the provider runs
  trap - EXIT                                            # from here on, failures preserve everything for inspection

  local pf="$LOG_ROOT/$slug.prompt.md"
  dispatch_prompt > "$pf"

  SESSION=""
  case "$provider" in
    fake)  run_fake "$slug" "$wt" "$pf" ;;
    codex) die "codex runner not implemented yet" ;;
    grok)  die "grok runner not implemented yet" ;;
  esac
  require_peon_contract "$wt" "$base_sha"
  update_meta_session "$slug" "$SESSION"

  echo "peon dispatched: $slug"
  echo "  provider: $provider  session: $SESSION"
  echo "  worktree: $wt"
  echo "  branch:   $branch (base $(git -C "$repo" rev-parse --short "$base_sha"))"
  echo "review with: peon report $slug"
}
```

Replace the dispatch stub line in the `case`:

```bash

meta_get() {
  local mf="$META_ROOT/$1.json"
  [ -f "$mf" ] || die "no peon found with slug: $1 (see 'peon list')"
  python3 -c 'import json,sys; print(json.load(open(sys.argv[1])).get(sys.argv[2],""))' "$mf" "$2"
}

find_wt() { meta_get "$1" worktree; }

require_wt() {
  [ -d "$1" ] || die "worktree missing for $2: $1 (orphaned — 'peon scrap $2' to clean up)"
}

cmd_list() {
  local filter=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --repo) [ -n "${2:-}" ] || die "--repo needs a value"; filter="$(resolve_repo "$2")"; shift 2 ;;
      *) die "unknown list option: $1" ;;
    esac
  done
  local mf slug provider branch repo wt report
  printf '%-22s %-7s %-28s %-8s %s\n' "SLUG" "PROV" "BRANCH" "REPORT" "REPO"
  for mf in "$META_ROOT"/*.json; do
    [ -f "$mf" ] || continue
    slug="$(basename "$mf" .json)"
    repo="$(meta_get "$slug" repo)"
    [ -z "$filter" ] || [ "$repo" = "$filter" ] || continue
    provider="$(meta_get "$slug" provider)"; branch="$(meta_get "$slug" branch)"
    wt="$(meta_get "$slug" worktree)"
    report="no"
    [ -d "$wt" ] || report="ORPHAN"
    [ -f "$wt/PEON_REPORT.md" ] && report="yes"
    printf '%-22s %-7s %-28s %-8s %s\n' "$slug" "$provider" "$branch" "$report" "$repo"
  done
}

cmd_report() {
  local slug="${1:-}"; [ -n "$slug" ] || die "usage: peon report <slug>"
  local wt base_sha
  wt="$(find_wt "$slug")"
  require_wt "$wt" "$slug"
  base_sha="$(meta_get "$slug" base_sha)"
  echo "== peon: $slug ($(meta_get "$slug" provider)) =="
  echo "task: $(meta_get "$slug" task)"
  echo
  if [ -f "$wt/PEON_REPORT.md" ]; then
    cat "$wt/PEON_REPORT.md"
  else
    echo "(no PEON_REPORT.md yet — peon may have failed or still be running)"
  fi
  echo
  echo "== commits =="
  git -C "$wt" log --oneline "$base_sha..HEAD"
  echo
  echo "== diffstat vs base =="
  git -C "$wt" diff --stat "$base_sha" HEAD
  if [ -n "$(git -C "$wt" status --porcelain)" ]; then
    echo
    echo "== WARNING: uncommitted changes in worktree =="
    git -C "$wt" status --short
  fi
}

cmd_diff() {
  local slug="${1:-}"; [ -n "$slug" ] || die "usage: peon diff <slug>"
  local wt
  wt="$(find_wt "$slug")"
  require_wt "$wt" "$slug"
  git -C "$wt" diff "$(meta_get "$slug" base_sha)" HEAD
}
```

```bash
poke_prompt() {
  cat <<EOF
Revision request from your reviewer on the work you already did in this worktree:

$feedback

Apply the requested changes and commit them to the current branch. Update PEON_REPORT.md to reflect the revision and commit that too. Same rules as before: leave the worktree clean, do not push, do not switch branches.
EOF
}

run_fake_resume() {
  local slug="$1" wt="$2" pf="$3"
  [ "${PEON_FAKE_NOOP:-0}" = "1" ] && return 0          # provider "succeeds" without doing anything
  ( cd "$wt" \
    && cat "$pf" >> "FAKE_WORK-$slug.txt" \
    && git add "FAKE_WORK-$slug.txt" && git commit -qm "fake: apply feedback" \
    && printf '\nrevised per feedback.\n' >> PEON_REPORT.md \
    && git add PEON_REPORT.md && git commit -qm "fake: update report" )
}

cmd_poke() {
  local slug="${1:-}" feedback="${2:-}"
  [ -n "$slug" ] || die "usage: peon poke <slug> \"<feedback>\""
  [ -n "$feedback" ] || die "no feedback given"
  local wt provider session pf pre
  wt="$(find_wt "$slug")"

  provider="$(meta_get "$slug" provider)"
  session="$(meta_get "$slug" session)"
  [ -n "$session" ] || die "no session recorded for $slug (dispatch failed before completing) — 'peon scrap $slug' and re-dispatch"
  pf="$LOG_ROOT/$slug.poke.md"
  mkdir -p "$LOG_ROOT"
  poke_prompt > "$pf"

    *) die "unknown provider in metadata: $provider" ;;

}
```

- `merge` refuses a **dirty peon worktree** (uncommitted provider work must be poked into commits or scrapped — never silently dropped) and a dirty target repo.

```bash
cleanup_peon() {
  local repo="$1" wt="$2" slug="$3" delflag="$4"
  git -C "$repo" worktree remove --force "$wt" 2>/dev/null \
    || { rm -rf "$wt"; git -C "$repo" worktree prune 2>/dev/null || true; }
  git -C "$repo" branch "$delflag" "peon/$slug" 2>/dev/null || true
  rm -f "$META_ROOT/$slug.json" "$LOG_ROOT/$slug".*      # meta ALWAYS goes — a slug must never stay reserved
}

cmd_merge() {
  local slug="${1:-}" into=""
  [ -n "$slug" ] || die "usage: peon merge <slug> [--into REF]"
  shift || true
  while [ $# -gt 0 ]; do
    case "$1" in
      --into) [ -n "${2:-}" ] || die "--into needs a value"; into="$2"; shift 2 ;;
      *) die "unknown merge option: $1" ;;
    esac
  done
  local wt repo branch task current pre_head
  wt="$(find_wt "$slug")"
  require_wt "$wt" "$slug"
  repo="$(meta_get "$slug" repo)"
  branch="$(meta_get "$slug" branch)"
  task="$(meta_get "$slug" task)"
  [ -z "$(git -C "$wt" status --porcelain)" ] \
    || die "peon worktree has uncommitted changes — 'peon poke $slug' to have them committed, or 'peon scrap $slug' to discard"
  require_clean "$repo" "merge target $repo"
  if [ -n "$into" ]; then
    current="$(git -C "$repo" symbolic-ref --short HEAD 2>/dev/null || echo DETACHED)"
    [ "$current" = "$into" ] || die "--into $into but $current is checked out — check out $into yourself first (peon never switches your branch)"
  fi
  pre_head="$(git -C "$repo" rev-parse HEAD)"
  if ! git -C "$repo" merge --no-ff --no-commit "$branch" >/dev/null 2>&1; then
    git -C "$repo" merge --abort 2>/dev/null || true
    die "merge of $branch does not apply cleanly — resolve manually or 'peon poke $slug' to have it rebase/fix"
  fi
  if git -C "$repo" diff --cached --quiet; then
    git -C "$repo" merge --abort 2>/dev/null || true
    git -C "$repo" reset -q --hard "$pre_head"
    die "nothing to merge from $branch (already up to date?)"
  fi
  if ! git -C "$repo" cat-file -e "$pre_head:PEON_REPORT.md" 2>/dev/null; then
    git -C "$repo" rm -qf PEON_REPORT.md 2>/dev/null || true   # review artifact, not product code
  fi
  git -C "$repo" commit -qm "merge peon/$slug: $(printf '%.60s' "$task")"
  cleanup_peon "$repo" "$wt" "$slug" -d
  echo "merged $branch into $(git -C "$repo" symbolic-ref --short HEAD 2>/dev/null || echo HEAD) and cleaned up"
}

cmd_scrap() {
  local slug="${1:-}"
  [ -n "$slug" ] || die "usage: peon scrap <slug>"
  local wt repo
  wt="$(find_wt "$slug")"
  repo="$(meta_get "$slug" repo)"
  if [ -d "$wt" ] && [ -n "$(git -C "$wt" status --porcelain 2>/dev/null)" ]; then
    echo "peon: warning: discarding uncommitted changes in $wt" >&2
  fi
  cleanup_peon "$repo" "$wt" "$slug" -D
  echo "scrapped $slug (worktree, branch, and metadata removed; work discarded)"
}
```

```bash
dry_run_stub() {  # $1=slug $2=wt, rest=cmdline — record the command; fake work so the contract gate passes
  local slug="$1" wt="$2"; shift 2
  printf '%s\n' "$*" >> "$LOG_ROOT/$slug.cmd"
  ( cd "$wt" \
    && echo "dry" >> DRY_RUN.txt && git add DRY_RUN.txt && git commit -qm "dry-run" \
    && printf '# Peon Report\n\ndry run.\n' > PEON_REPORT.md \
    && git add PEON_REPORT.md && git commit -qm "dry-run report" )
  SESSION="dry-run"
}

extract_codex_session() {  # $1=jsonl log — prints session id or exits non-zero (fail closed)
  python3 - "$1" <<'PYEOF'
import json, sys
KEYS = ("session_id", "conversation_id", "thread_id")   # preference order
found = {k: [] for k in KEYS}
def walk(o):
    if isinstance(o, dict):
        for k, v in o.items():
            if k in KEYS and isinstance(v, str) and v and v not in found[k]:
                found[k].append(v)
            walk(v)
    elif isinstance(o, list):
        for i in o:
            walk(i)
for line in open(sys.argv[1], errors="replace"):
    line = line.strip()
    if not line:
        continue
    try:
        walk(json.loads(line))
    except ValueError:
        continue
for k in KEYS:
    if len(found[k]) == 1:
        print(found[k][0]); sys.exit(0)
    if len(found[k]) > 1:
        sys.exit(2)      # ambiguous — refuse to guess
sys.exit(1)              # none found
PYEOF
}

grok_approve_args() {
  case "$GROK_APPROVE" in
    mode:*) printf -- '--permission-mode %s' "${GROK_APPROVE#mode:}" ;;
    always) printf -- '--always-approve' ;;
    *) die "invalid GROK_APPROVE: '$GROK_APPROVE' (use mode:<m> or always)" ;;
  esac
}

run_codex() {
  local slug="$1" wt="$2" pf="$3" log="$LOG_ROOT/$slug.codex.jsonl"
  if [ "${PEON_DRY_RUN:-0}" = "1" ]; then
    dry_run_stub "$slug" "$wt" "codex exec --json -s workspace-write -c approval_policy=never - < $pf"
    return
  fi
  ( cd "$wt" && codex exec --json -s workspace-write -c approval_policy=never - < "$pf" ) \
    > "$log" 2>"$LOG_ROOT/$slug.codex.err" || die "codex exec failed — see $log"

    || die "could not extract an unambiguous codex session id from $log — poke would be impossible; inspect the log, then scrap or fix extract_codex_session"
```

```markdown
# Peon Poke — Farm Implementation Work to External CLI Agents

`/plan-check` pulls **opinions** in; `/peon-poke` pushes **labor** out. An external agent (a "peon") does an implementation chore in an isolated git worktree; Claude — the foreman — reviews the work and merges it or sends it back. Nothing reaches the real working tree without review and an explicit merge.

All mechanics live in the `peon` script — never hand-roll worktrees or provider CLI calls. If `command -v peon` fails, tell the user to install it (README of ytubecoder/codex-in-claude) and stop.

## Commands

| Command | Does |
|---|---|
| `peon dispatch <codex\|grok> "<task>" [--repo DIR] [--base REF] [--slug NAME] [--force]` | Create worktree + `peon/<slug>` branch, run the provider inside it. Synchronous — background it to keep working. Fails loudly if the peon breaks contract (no commits / no report / dirty tree), preserving the worktree for inspection. |
| `peon list [--repo DIR]` | Active peons, report status, orphan detection |
| `peon report <slug>` | PEON_REPORT.md + commits + diffstat vs base (+ dirty-tree warning) |
| `peon diff <slug>` | Full diff vs base |
| `peon poke <slug> "<feedback>"` | Resume the same provider session for revisions; fails loudly on a no-op round |
| `peon merge <slug> [--into REF]` | After review: merge, strip the report, clean up. `--into` only asserts REF is already checked out — peon never switches your branch. |
| `peon scrap <slug>` | Discard the work, remove worktree + branch + metadata |

Slugs are globally unique across repos. Grok approval strategy is `GROK_APPROVE` (`mode:<m>` or `always`).

## Workflow

1. **Scope the task.** Peons execute; they don't design. Good: a feature slice, a refactor, tests, docs — one well-defined chore with clear done-criteria. If the task is ambiguous, tighten it (or brainstorm with the user) before dispatch. Include acceptance criteria and relevant file paths in the task text.
2. **Dispatch.** One peon per task. Parallel peons = *different* tasks (never the same task to two providers — that's plan-check's council, not labor). Provider: user's choice if stated, else either. Dirty repo? Ask the user before `--force` — dispatch branches from the last *commit*, so uncommitted work is invisible to the peon.
3. **Wait.** Dispatch is synchronous (minutes). Background it and continue other work, or wait if idle. If a dispatch hangs (stuck provider), kill the process and `peon scrap` the slug — the worktree holds whatever happened.
4. **Review like a code review.** `peon report <slug>`, then `peon diff <slug>`. Judge correctness, conventions, tests, scope-creep against your conversation context — you know things the peon does not. Then either `peon poke <slug> "<specific feedback>"` (repeatable) or `peon merge <slug>`.
5. **Report to the user.** Summarize what the peon did, your review verdict, and what you merged or why you poked/scrapped.

## Rules

- **Never merge without reviewing the diff.** Draft-until-reviewed is the whole point.
- **Never bypass the script** to poke provider sessions or touch `peon/*` branches by hand.
- Peons are sandboxed to their worktree and may lack network access — don't dispatch tasks needing `npm install` of new deps without checking the result carefully.
- A failed peon leaves its worktree AND metadata for inspection: `peon report` still works; `peon scrap` cleans up. Logs live in `~/.peon/logs/` and are removed on merge/scrap; a long-ignored failed peon is the only thing that accumulates — `peon list` surfaces them.
- Merge conflicts are the foreman's job: resolve manually or `peon poke` the peon to rebase onto an updated base.
- Very large repos: `git worktree add` copies nothing but checkout time and LFS smudge can be slow — prefer `--base` on a small stable ref where possible.
```
